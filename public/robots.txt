# Structure note: robots.txt groups do NOT inherit from each other. A crawler
# obeys exactly one group — the most specific one naming it — and ignores every
# rule in every other group, including "User-agent: *".
#
# This file previously gave Googlebot, Bingbot and ~25 other crawlers their own
# group containing nothing but "Allow: /". That meant the "Disallow: /teacher/"
# sitting under "User-agent: *" applied to none of them: the only crawlers it
# ever bound were the ones not named anywhere. Every rule below is therefore
# declared once, against a single group that names every crawler explicitly,
# so the disallow list actually binds to the crawlers it is written for.

# groups starts from the full list rather than silently dropping someone.

# --- Authenticated app surfaces --------------------------------------------
# Every path below sits behind <ProtectedRoute> in src/App.tsx. A signed-out
# visitor — which is what every crawler is — gets a client-side redirect to
# /auth, so the crawler ends up indexing the sign-in screen under the app's URL.
# Nine of these were being advertised to crawlers by the SiteNavigationElement
# JSON-LD in index.html, so they were discovered and crawled despite never
# appearing in the sitemap. The result was a cluster of URLs that all resolved
# to the same sign-in page: identical meta descriptions, almost no words, and a
# text-to-HTML ratio near zero.
#
# There is no version of these pages a crawler can usefully see, so they are
# excluded outright rather than made thinner-but-indexable.

# --- Duplicate parameterised URLs -------------------------------------------
# /auth itself stays indexable (it ranks for brand queries), but the bounce-back
# URLs a guest lands on after hitting a gated route carry ?redirect= and are
# duplicates of it. ?explore= is deliberately NOT blocked: it is a duplicate of
# "/", and the canonical tag already consolidates it — blocking it would stop
# crawlers reading that canonical at all.
Disallow: /*?redirect=
